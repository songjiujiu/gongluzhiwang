# 无尽公路：单关持续挑战

2026-10-08，本次规则替代旧版三关与 75 秒通关目标。玩法参考跑酷游戏随存活时间逐步加压的节奏，保留公路驾驶主题与三车道操作。

## 一局流程

点击开始，从中间车道出发。车辆自动巡航，玩家通过左右换道和气浪解围。没有终点或必须完成的事件数；只在耐久耗尽时结算。得分随行驶距离和成功躲避障碍增长，碰撞扣分。结算显示距离、存活时间、最高车速和躲避数量，再挑战会重置整局难度和车辆状态。

## 难度与公平性

巡航速度随时间平滑提高，障碍波次的间隔逐渐缩短。开局以单车道障碍为主，随后混入双车道阻挡、固定路障和有预告的橙色变线车辆。阶段提示帮助玩家感知压力变化，不切换关卡或重置车速。

| 参数 | 本次实现 |
| --- | --- |
| 巡航速度 | 从 76 km/h 平滑趋近 228 km/h；额外加速上限 240 km/h |
| 目标波次间隔 | 从 4.6 秒趋近 1.1 秒；前方拥挤时推迟生成 |
| 生成预留反应时间 | 从 5 秒趋近 2.6 秒，并受可见距离与安全间距约束 |
| 内容加入时间 | 30 秒橙车预告变线，60 秒增加双道障碍与路障 |
| 阶段提示 | 每 30 秒提升一档，最多 4 档；车速与密度继续趋近安全上限 |
| 换道 | 每格约 0.2 秒，快速连续输入可缓冲到目标车道 |

每组障碍保留至少一个安全车道；相邻组的安全车道最多横移一格。动态车辆只在本组其他车道内变线，避免封住预留出口。难度有速度、反应时间和生成频率的边界，以免无限增长到无法操作或无法辨认。

难度不会通过延迟输入或降低转向能力提高。左右换道保持灵敏，压力来自更快的判断、连续变线和应急资源管理。

## 应急资源

手机驾驶采用滑动操作：左右滑动每次换一条车道，点击气浪技能释放气浪。公路和底部提示区均可滑动，气浪通过右侧半透明圆形技能按钮释放。气浪保留范围与冷却，推开近前车辆；固定路障仍需避让。普通换道始终是主要操作。

## 界面与纪录

主菜单仅保留一个开始入口。HUD 显示车速、难度、距离、时长、耐久、得分。暂停页可继续、重开或返回首页。最高分、最长距离与最长存活时间作为无尽模式独立纪录保存，避免与旧关卡分数混算。

## 验证

规则测试覆盖长局不自动结束、难度增长、碰撞、暂停、重试、结算防重入、障碍通路以及多个随机种子的公共操作实跑。浏览器预览检查共享 Canvas 界面、键盘/触控、暂停和纪录持久化，包含 390×844 与 320×568 视口。实际测试结果及数值见游戏目录 README 和 `research/endless-preview/`；浏览器不等同于手机真机。

强度 3（60 秒）播放用户提供视频 0–32 秒的铺垫段，强度 4（90 秒）切换视频 40–72 秒高能量段。两段各自循环；暂停、后台和静音停止，恢复后继续，重开清零。
