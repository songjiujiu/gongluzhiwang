# 强度配置

修改 `公路之王/src/difficulty-config.js`，保存后重新编译小游戏。仍为一局无尽模式，九档自动升级：第一档轻松教学，第二档难度陡增，之后持续加压。

## 选择开局强度

修改文件顶部的 `startTier`，可选整数 1–9。当前配置 `"startTier": 1`。例如 `"startTier": 4` 表示直接从强度 4 的起始速度和黑夜场景开始。首页会显示当前开局强度。

选择任意强度时，从该档第 0 秒开始；前八档持续满该档 `durationSeconds` 后进入下一档，强度 9 无限持续。生存时间、距离和得分仍从 0 开始，重新挑战仍使用同一个开局强度。省略该字段按 1 处理。4/5 直接进入夜间，6–9 直接进入清晨雾景。

| 强度 / 时间 | 巡航目标 km/h | 波次间隔（秒） | 双障碍概率 | 路障概率 |
| --- | --- | --- | --- | --- |
| 1 轻松起步 / 0–10 秒 | 76 → 90 | 4.6 → 4.1 | 0% | 0% |
| 2 地狱开局 / 10–40 秒 | 240 → 320 | 1.1 → 0.85 | 70% | 15% |
| 3 极限闪避 / 40–70 秒 | 380 → 480 | 0.8 → 0.65 | 82% | 25% |
| 4 黑夜狂飙 / 70–130 秒 | 560 → 760 | 0.6 → 0.45 | 92% | 32% |
| 5 深夜极限 / 130–190 秒 | 800 → 900 | 0.44 → 0.40 | 94% | 35% |
| 6 晨雾初现 / 190–250 秒 | 950 → 1050 | 0.39 → 0.35 | 95% | 38% |
| 7 雾海疾驰 / 250–310 秒 | 1100 → 1200 | 0.34 → 0.30 | 96% | 41% |
| 8 浓雾穿行 / 310–370 秒 | 1250 → 1350 | 0.29 → 0.26 | 97% | 44% |
| 9 迷雾极限 / 370 秒后 | 1400 → 1600 | 0.25 → 0.20 | 98% | 47% |

表中时间以强度 1 开局计算；若改为强度 4 开局，120 秒后进入强度 6。

第二档开始出现变道车和固定路障；每波仍保留空车道，相邻波次的空车道最多相差一条。升级时将旧档剩余生成等待缩短至最多 0.6 秒（拥挤时仍延期）。巡航目标陡增后车辆逐步加速，碰撞停车后的加速和避障恢复逻辑保持一致。表中间隔为请求间隔，实际波次仍受安全距离和可见范围约束，不代表强制每隔该时间塞入障碍。

| 配置字段 | 含义 |
| --- | --- |
| `label` | 界面显示的强度名称 |
| `scene` | `sunset` 黄昏、`night` 黑夜、`dawn` 清晨；可以逐档修改 |
| `fogDensity` | 清晨雾密度，0–0.04；0 关闭额外晨雾，省略为 0.014 |
| `durationSeconds` | 本档持续秒数。前八档结束后进入下一档；第九档无限持续，该值控制趋近最终速度和密度的时间尺度 |
| `speedStart` / `speedEnd` | 本档巡航起始与最终速度，km/h，范围大于 0，没有固定最大速度限制 |
| `spawnStart` / `spawnEnd` | 本档起始与最终障碍生成间隔，秒，数值越小越密集；前方拥挤时仍会推迟生成 |
| `reactionSeconds` | 生成障碍时预留的反应秒数，大于 0 |
| `mergeWarningMin` / `mergeWarningMax` | 变道车打灯后等待秒数的随机范围；最小值大于 0，最大值不小于最小值，省略时均为 1.1 秒 |
| `mergeChance` | 车辆变道概率，0–1；0 关闭变道，1 为所有符合安全条件的波次开启变道 |
| `doubleChance` | 一组生成双障碍的概率，0–1 |
| `barrierChance` | 一组生成固定路障的概率，0–1 |
| `maxActiveObstacles` | 同时存在的前方有效障碍上限，整数，至少 2 |

例如前三档时间分别改为 `20`、`40`、`60`，则强度 2 在第 20 秒开始，强度 3 在第 60 秒开始，强度 4 在第 120 秒开始。修改某档的概率和速度只影响该档。

前八档的速度和生成间隔按时间线性变化；第九档平滑趋近终值，不会再切换强度。长按额外加速仍为 22 km/h，不再设固定最大速度上限。配置概率受车辆间距、预告和安全出口规则约束，保证不会为了达到概率而强制穿车。

错误的字段会在启动时明确报出所在强度和字段名。各档配置在创建游戏时读取，修改后重新编译生效。

升级进入强度 4 时，场景在 2.5 秒内从黄昏过渡到黑夜，开启路灯照明与车前照明。触发时间跟随所选开局强度及各档 `durationSeconds`，不固定写死为 70 秒。暂停保留过渡进度；`startTier: 4` 开局和重开直接使用黑夜。

变道与短反应窗口：强度 2/3/4 的 `reactionSeconds` 分别为 1.05/0.85/0.70 秒。启用变道的档位每波取配置反应时间的 80%–100%，按当前车速计算出现距离，最低保留 18 米与约 0.55 秒接近时间；已有车流的安全间距可能使实际反应窗口变长。第一档保持教学节奏。

强度 2 打灯等待随机 0.35–0.55 秒，强度 3 为 0.25–0.40 秒，强度 4 为 0.18–0.30 秒。预警启动点同时考虑这次等待时长、横移时间和随机余量。双车波次随机排列左右前后顺序，并随机选前车或后车变道；可变道的双车间距随机 10–16 米，让相邻车辆有真实变道空间。目的车道或横移路径被其他车占用时仍等待，保留每波空车道，不穿越车辆或固定路障。

极高速度配置：仪表速度与长按目标仍按配置计算；超过240的数值使用对数缩放转换为道路场景移动速度，避免一帧越过整个可见道路。障碍预留距离限制在可见范围内，因此1000、1500、20000、40000等配置仍会生成障碍。可见道路长度有限，极高速度时实际预留反应时间可能小于配置值。前方拥挤时仍推迟生成，避免把障碍重叠放置。

强度 4–5 保持黑夜；强度 6 在 2.5 秒内转为清晨，使用冷色天空、淡金色太阳与低空距离雾。强度 6–9 的雾密度依次为 0.014、0.018、0.021、0.024，并在换档时平滑过渡。额外晨雾从镜头前 14 米以外增强，保留近处车辆和路障；远景随距离淡入雾色。`startTier: 6` 可直接预览晨雾。
