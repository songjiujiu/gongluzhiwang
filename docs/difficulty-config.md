# 强度配置

修改 `公路之王/src/difficulty-config.js`，保存后重新编译小游戏。仍为一局无尽模式，四档自动升级：第一档轻松教学，第二档难度陡增，之后持续加压。

| 强度 / 时间 | 巡航目标 km/h | 波次间隔（秒） | 双障碍概率 | 路障概率 |
| --- | --- | --- | --- | --- |
| 1 轻松起步 / 0–10 秒 | 76 → 90 | 4.6 → 4.1 | 0% | 0% |
| 2 地狱开局 / 10–40 秒 | 240 → 320 | 1.1 → 0.85 | 70% | 15% |
| 3 极限闪避 / 40–70 秒 | 380 → 480 | 0.8 → 0.65 | 82% | 25% |
| 4 绝境狂飙 / 70 秒后 | 560 → 760 | 0.6 → 0.45 | 92% | 32% |

第二档开始出现变道车和固定路障；每波仍保留空车道，相邻波次的空车道最多相差一条。升级时将旧档剩余生成等待缩短至最多 0.6 秒（拥挤时仍延期）。巡航目标陡增后车辆逐步加速，碰撞停车后的加速和避障恢复逻辑保持一致。表中间隔为请求间隔，实际波次仍受安全距离和可见范围约束，不代表强制每隔该时间塞入障碍。

| 配置字段 | 含义 |
| --- | --- |
| `label` | 界面显示的强度名称 |
| `durationSeconds` | 本档持续秒数。前三档结束后进入下一档；第四档无限持续，该值控制趋近最终速度和密度的时间尺度 |
| `speedStart` / `speedEnd` | 本档巡航起始与最终速度，km/h，范围大于 0，没有固定最大速度限制 |
| `spawnStart` / `spawnEnd` | 本档起始与最终障碍生成间隔，秒，数值越小越密集；前方拥挤时仍会推迟生成 |
| `reactionSeconds` | 生成障碍时预留的反应秒数，大于 0 |
| `mergeChance` | 车辆变道概率，0–1；0 关闭变道，1 为所有符合安全条件的波次开启变道 |
| `doubleChance` | 一组生成双障碍的概率，0–1 |
| `barrierChance` | 一组生成固定路障的概率，0–1 |
| `maxActiveObstacles` | 同时存在的前方有效障碍上限，整数，至少 2 |

例如前三档时间分别改为 `20`、`40`、`60`，则强度 2 在第 20 秒开始，强度 3 在第 60 秒开始，强度 4 在第 120 秒开始。修改某档的概率和速度只影响该档。

前三档的速度和生成间隔按时间线性变化；第四档平滑趋近终值，不会再切换强度。长按额外加速仍为 22 km/h，不再设固定最大速度上限。配置概率受车辆间距、预告和安全出口规则约束，保证不会为了达到概率而强制穿车。

错误的字段会在启动时明确报出所在强度和字段名。各档配置在创建游戏时读取，修改后重新编译生效。

极高速度配置：仪表速度与长按目标仍按配置计算；超过240的数值使用对数缩放转换为道路场景移动速度，避免一帧越过整个可见道路。障碍预留距离限制在可见范围内，因此1000、1500、20000、40000等配置仍会生成障碍。可见道路长度有限，极高速度时实际预留反应时间可能小于配置值。前方拥挤时仍推迟生成，避免把障碍重叠放置。
