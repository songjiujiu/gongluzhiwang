# 公路之王 · 单关无尽版

原生 JavaScript + WebGL 三维场景 / Canvas 界面竖屏小游戏。只有一条无限延伸的公路：存活越久，车辆越快，障碍越密集，连续换道与预判要求越高。耐久耗尽后结束，挑战最高分、最长距离和最长存活时间。

当前游戏直接加载 Blender 导出的压缩三维网格，使用实时 WebGL 绘制车辆、路障、棕榈和岩石，搭配同一透视下的道路、护栏、山体和海面。镜头跟随换道，保证主车保持在屏幕内。PNG 用于菜单展示与兼容后备画面。模型源文件位于上一级 `art/blender/`；详见 [Blender 美术说明](../docs/blender-art.md)。

## 导入与启动

在抖音开发者工具中导入 **`公路之王` 文件夹**，不要选择上一级工作区。入口 `game.js`，原生小游戏配置及 AppID `tt9b11edac056834d607` 保持不变。无需 npm 安装或构建，重新编译后点击“开始挑战”。

## 操作

| 操作 | 手机触控 | 浏览器键盘 |
| --- | --- | --- |
| 左右换道 | 左右滑动，每次换一条车道 | A / D 或 ← / → |
| 加速 | 自动巡航持续提速，无需按键 | W / ↑ 可额外加速 |
| 气浪解围 | 点击右侧半透明圆形气浪按钮，推开近前车辆 | F |
| 暂停/继续 | 右上角暂停按钮 | Esc |
| 开始/再挑战 | 首页或结算页主按钮 | Enter |
| 立即重开 | 暂停页重新开始 | R |

公路和底部提示区都支持滑动，仅气浪技能保留点击按钮。每次滑动只触发一次操作，连续两次左右滑动可跨两条车道。左右滑动换道，点击气浪技能释放气浪。气浪冷却 10 秒，只推开近前车辆，固定路障仍需换道。离开页面或切到后台会暂停并释放按住的操作，回来后手动继续。

## 无尽规则

- 取消原三关、75 秒终点、化解 3 次事件目标和星级通关。整局持续增加距离和得分，直到耐久为 0。
- 起步以单道障碍为主，随后增加固定路障、双车道阻挡、错位组合与带方向预告的橙色变线车。
- 巡航速度平滑上升，障碍生成间隔缩短；阶段提示表示同一局难度升级，不会重置进度。
- 每组障碍保留安全出口，相邻出口只相差一条车道。前后障碍还会保持纵向间距，减少组合叠成必撞局面的情况。
- 碰撞扣 26 耐久与 120 分，分数最低为 0，车速立即归零。左右滑到旁边且有空位的车道后，从静止重新加速；同车道后车保持间距排队，其他车道继续通行。碰撞后有 2.1 秒伤害保护，停车等待期间不会反复扣耐久，四次碰撞耗尽耐久。
- 持续行驶与躲避障碍获得分数。最高分、最长距离和最长存活时间分别记录，使用独立无尽存档 `roadking.endless.best.v1`，不混入旧关卡成绩。
- 重开会重置车速、难度、车流、能量、冷却、碰撞和本局得分。本地纪录保留。

## 测试与本地试玩

从上一级工作区执行：

```powershell
node --test tests/*.test.js
node preview/serve.js 4179
```

访问 [http://127.0.0.1:4179/](http://127.0.0.1:4179/)。若端口已有服务，直接访问并刷新。浏览器与抖音环境加载同一份 `game-core.js` 和 `game-app.js`。浏览器预览工具不需要放入抖音发布包。

规则与平台测试 **34/34 通过**。覆盖障碍车变道路径占用、邻车接近预测、交叉变道和高速跟车防穿越，以及撞后停车、换道重新起步、后车排队和原生资源读取。六个随机种子的六分钟驾驶逐帧检查车流无重叠。`tools/verify_blender_preview.cjs` 复现邻车阻挡变道，检查等待、空隙出现后变道、长时间车流和结算。实际游戏截图和报告输出至 `research/blender-preview/`。

本次验证范围为 Node 规则/平台测试与共享源码浏览器预览（390×844、320×568）。本次无尽修改尚未在抖音模拟器或手机真机重验，也未上传、审核或发布。`research/douyin-preview/` 中的记录与旧版 PDF 是原三关版本的历史资料。

## 文件

- `game.js`：小游戏入口。
- `src/game-core.js`：独立于平台的规则、难度与障碍生成。
- `src/game-app.js`：Canvas 公路、车辆、路障、HUD 和触控操作。
- `src/platform.js`：抖音触控、生命周期、存储、音频、振动适配。
- `audio/`：原创合成音效。
- [现行无尽模式设计](../docs/endless-mode.md)。

车辆、路障和路边景观使用项目内 Blender 渲染素材，道路与界面由 Canvas 绘制，不需要在线下载素材。保留的 `RoadKingUnity/` 是历史原型，本次交付入口为本目录的抖音原生小游戏。
